## User story
As a family member, I want to see where and with what camera a photo was taken, and to filter by date, so that I can find old photos quickly.

## Acceptance criteria (draft)
- **AC-1** The viewer shows these EXIF details when present: camera model, lens, exposure, ISO, and GPS location (shown as a map link).
- **AC-2** The gallery can be filtered by a date range and by year/month.
- **AC-3** A search field finds images by file name and uploader.
- **AC-4** Users can choose whether GPS data is shown or hidden for the whole gallery (privacy).
